Шаг 1. Создание окружения и установка зависимостей

Мы создадим окружение с именем afpredictor и сразу установим в него Python, сам antiSMASH и все необходимые Python-библиотеки для машинного обучения и парсинга данных.

Для установки потребуются каналы bioconda (для antiSMASH) и conda-forge (для всего остального).

Откройте терминал и выполните следующую команду:

mamba create -n afpredictor -c conda-forge -c bioconda \
    python=3.10 \
    antismash \
    biopython \
    pandas \
    numpy \
    scikit-learn \
    joblib \
    shap

Шаг 2. Активация окружения

mamba activate afpredictor

Эту команду нужно будет выполнять каждый раз перед запуском ваших скриптов.
Шаг 3. Загрузка баз данных для antiSMASH (Обязательно)

Если вы устанавливаете antiSMASH через mamba впервые на этом сервере/компьютере, ему необходимо скачать актуальные профили HMM, базы данных кластеров и Pfam.

В активированном окружении выполните:

download-antismash-databases

Дождитесь окончания загрузки. Для этого потребуется стабильное интернет-соединение и несколько гигабайт свободного места на диске.
Шаг 4. Проверка работоспособности

Чтобы убедиться, что всё установлено правильно, можно выполнить пару быстрых проверок.

1. Проверка antiSMASH:
Bash

antismash --version

Вывод должен показать установленную версию (например, antiSMASH 8.x.x).

2. Проверка Python-библиотек:
Bash

python -c "import pandas, Bio, joblib, shap, sklearn; print('Все ML-библиотеки успешно импортированы')"

Если команда выполнилась без ошибок (Traceback), значит, все зависимости для вашего ML-скрипта установлены корректно.
Шаг 5. Запуск скриптов

Теперь вы можете запускать ваш пайплайн. Убедитесь, что окружение активно (в терминале слева должно быть написано (afpredictor)).

Пример запуска объединенного пайплайна:
Bash

python AFPredictor_full.py \
    -i /путь/к/fasta/файлам \
    -e fasta \
    -o /путь/к/результатам/antismash \
    -t 16 \
    -m /путь/к/папке/с/моделями \
    --out_predict /путь/к/финальным/таблицам
