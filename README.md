# AFPredictor: Прогнозирование противогрибковой активности биосинтетических генных кластеров

**Разработчик:** аспирант Максим К.

Веб-приложение **AFPredictor** предназначено для автоматизированного анализа вторичных метаболитов микроорганизмов. Платформа применяет модели машинного обучения к выходным данным системы antiSMASH для оценки вероятности наличия противогрибковой (antifungal) активности у выявленных биосинтетических генных кластеров (BGC).

## Описание работы
В основе классификации лежат ансамблевые алгоритмы (включая Random Forest и PU-обучение), натренированные на композиционных признаках кластеров: предсказанных мономерах (для NRPS/PKS), архитектуре Pfam-доменов и данных гомологии из базы MIBiG. 
Для обеспечения прозрачности прогнозов интегрирован SHAP-анализ, который визуализирует вклад отдельных генетических компонентов (генов, доменов) в итоговый результат.

## Режимы анализа
Платформа поддерживает два сценария:
1. **Полный пайплайн (Full Pipeline):** Обработка сырых геномных последовательностей. Требует локально установленного ядра antiSMASH.
2. **Анализ готовых данных (ML-Only):** Моментальная обработка `.json` файлов (формат antiSMASH v6/v7), полученных ранее или загруженных с официального веб-сервера antiSMASH. 

Инструмент разработан для *in silico* приоритизации генных кластеров, что позволяет значительно сузить круг мишеней для последующей экспериментальной валидации новых фунгицидов в лабораторных условиях.
